Veyra IDE 2.1.0 improves live editing and adds a project-aware assistant with reviewed repair proposals.

### Changes

- Completion menus and diagnostic underlines survive asynchronous semantic highlighting.
- Source revisions track text edits separately from formatting, preserving background navigation, Git annotations and local suggestions.
- The project agent reads the active buffer, related classes, project configuration and compiler/LSP diagnostics. Proposed changes are reviewed before being applied to editor buffers.
- API providers can be added and edited inside Veyra through the optional Beamcore runtime. Credentials are encrypted in an IDE-owned store; the imported configuration is preserved.
- Project search, the focused file tree and agent context share `.gitignore` and `.veyraignore` rules, including nested patterns and negation.
- Long-file navigation, gutter selection, bookmarks and authorship annotations have regression coverage.
- The Dock application icon is explicitly loaded from the transparent PNG.

### Downloads

Windows x86-64: setup EXE or portable ZIP. macOS ARM64 and x86-64: DMG or PKG. Linux x86-64: DEB, RPM or tar.gz.

All packages include the approximately 491 MB Qwen2.5-Coder 0.5B model. Windows and macOS packages include Qt. Linux packages use system Qt libraries and target Ubuntu 24.04-compatible systems. SDKs, language servers and debugger adapters are connected separately.

Use `SHA256SUMS.txt` to verify downloads. `build-info.txt` identifies the exact source commit and CI run. macOS bundles are ad-hoc signed and not notarized; Windows packages are not code-signed.
