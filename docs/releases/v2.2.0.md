# Veyra IDE 2.2.0

Remote projects and database tools are now part of the native workspace.

- Open a server project through **File → Remote development…**. Edit UTF-8 files, run server commands and connect a server-side language server. Existing OpenSSH configuration, keys, agent authentication and jump hosts are supported.
- Review SSH host fingerprints before adding trust. Saves detect changed server files and offer a side-by-side comparison. New local edits made during an upload remain unsaved until their own upload completes.
- Open **View → Database** for independent connection tabs, table browsing, editable grids, paging, filtering, sorting, explicit NULL values and CSV display export.
- Run SQL in a separate connection worker. Query-result paging uses a bounded cache and never replays a data-changing statement. Staged table updates use bound values and conflict checks on transactional tables.
- Drivers are discovered from Qt plugins. SQLite ships in release packages; other SQL engines require compatible plugins and client libraries. SQLite and PostgreSQL have integration tests.
- New screens support English and Russian. The README includes a recording of the actual editor and native table/remote workspace screenshots.

Remote servers need a POSIX shell. Authentication currently uses keys or a local SSH agent; password prompts and database SSH tunnels are not included. Remote command disconnection does not guarantee termination of detached server processes.

Packages include the approximately 491 MB local Qwen model. Windows and macOS include Qt. Linux uses system Qt libraries. macOS packages are ad-hoc signed; Windows packages are not code-signed. Verify downloads using the attached SHA256SUMS.txt.
