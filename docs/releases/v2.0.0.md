Veyra IDE 2.0.0 is a native C++20/Qt desktop editor for local SDKs and language servers.

### Included

- Project creation, CMake target discovery, build/run controls, terminal, and Git tools.
- LSP completion, semantic highlighting, diagnostics, navigation, rename, and formatting.
- Live thread feedback and in-process code completion with the bundled 0.5B model.
- Native LLDB DAP client, automatic bracket/quote pairing, document recovery, and English/Russian UI.

### Downloads

| Platform | Files |
| --- | --- |
| Windows x86-64 | Setup EXE or portable ZIP |
| macOS Apple Silicon | DMG or PKG |
| macOS Intel | DMG or PKG |
| Linux x86-64 | DEB, RPM, or tar.gz |

All packages include the local model. Windows and macOS packages include Qt; Linux packages use system libraries and were built on Ubuntu 24.04. SDKs, language servers, and debugger adapters are configured separately.

Verify a download with `SHA256SUMS.txt`. `build-info.txt` records the source commit and successful CI run used to produce these files.

### Platform notes

- macOS applications use an ad-hoc signature and are not notarized. Windows installers are not code-signed.
- Native debugging requires a working LLDB DAP installation. The Windows CI runner's incomplete adapter was rejected during discovery, so its backend integration test was skipped. Native debugging was exercised on Linux and macOS.
- Language features depend on the capabilities of the selected SDK and language server.
